# Istruzioni per agenti AI

Questo repository è un template didattico, non un progetto applicativo. Conserva la struttura `docs/`, `modules/`, `projects/`. Scrivi spiegazioni chiare in italiano, con esempi eseguibili quando appropriato. Non aggiungere framework o dipendenze senza motivazione. Prima di proporre una modifica esegui `npm run validate`. Non inserire dati sensibili.
